2.1  Knowledge Base Data Schema
Content is organized in PostgreSQL & vector storage:
• Application Registry: ID, Name, Category, Owner, Auth Tier.
• Module Records: AppID, ModuleName, Purpose, ScreenRoute.
• Feature & Settings: ModuleID, SettingKey, ActionWorkflow,
  PermittedRoles ﴾Admin/Employee ,﴿StepByStepGuide.
• FAQ Bank: Question, Answer, Tags, LastVerifiedDate, Hits.
• Vector Embeddings: 768‐dim vectors linked to parent
  record IDs with HNSW cosine distance indexing.2.2  Hybrid Retrieval Pipeline ﴾RAG﴿
Combines lexical and semantic retrieval:
• Stage 1 ﴾Fast Filter :﴿Keyword exact match in PostgreSQL
  for immediate FAQ identification <﴾30ms.﴿
 •Stage 2 ﴾Dense Search :﴿Embed user query via Gemini
  text‐embedding‐004; query pgvector top‐k ﴾k=3.﴿
 •Stage 3 ﴾Reranking :﴿Reciprocal Rank Fusion ﴾RRF ﴿scores
  BM25 and vector results; discards scores < 0.65 threshold.
• Chunking Standard: 350‐token semantic chunks with
  50‐token sliding overlap to preserve context boundaries.

Protocol 1: Truncated Exponential Backoff with Jitter AUTOMATED RETRY
Upon HTTP 429 ﴾Resource Exhausted ,﴿the client executes truncated exponential backoff: delay = min﴾30s, base * 2^attempt + ﴿random_jitter﴾0, 500ms .﴿Prevents
thundering‐herd spikes on Google AI Studio endpoints and guarantees automatic recovery without dropped requests.
Protocol 2: Dual‐Model Quota Pooling & Dynamic Routing QUOTA POOLING
Gemini 3 Flash ﴾10 RPM ﴿and Gemini 3.1 Flash‐Lite ﴾15 RPM ﴿operate under independent quota buckets. The FastAPI gateway dynamically offloads fast intent classification
and FAQ cache matching to Flash‐Lite, preserving Flash quota for multi‐step reasoning.
Protocol 3: Automated Multi‐Cloud Circuit Breaker FAILOVER CIRCUIT
A sliding 60‐second health monitor tracks provider error rates. If Google API errors exceed 5% or latency exceeds 3,000ms, the circuit breaker opens, automatically shifting
query traffic to OpenAI GPT‐4o mini or DeepSeek‐V4.1 with zero end‐user downtime.
Protocol 4: Context Caching & Prefix Optimization 75% TOKEN DISCOUNT
Static module schemas, enterprise workflow definitions, and permanent system instructions are registered with Gemini's Context Caching. Frequent queries leverage
cached prefix tokens, cutting TTFT by 60% and reducing billable token charges by up to 75%.

7.4  Technical Glossary of Terms
LLM ﴾Large Language Model:﴿ Advanced neural network trained on vast text data capable of natural language reasoning.
Grounded Generation ﴾RAG:﴿ Pattern where retrieved authoritative application documentation is injected into model prompt.
Embeddings ﴾Vector:﴿ High‐dimensional mathematical representations ﴾768‐dim ﴿capturing semantic meaning of text.
Vector Database ﴾pgvector:﴿ Database optimized for ultra‐fast cosine similarity searches across documentation vectors.
Rate Limits ﴾RPM/TPM/RPD:﴿ Provider enforcement quotas: Requests Per Minute, Tokens Per Minute, and Requests Per Day.
Hallucination Guardrails: Architectural rules and prompt instructions forcing the model to refuse when facts are absent.
TTFT ﴾Time To First Token:﴿ Latency duration between sending user prompt and receiving the first token of the generated response.
HNSW Indexing: Hierarchical Navigable Small World vector graph indexing enabling sub‐10ms similarity searches.
BM25 Keyword Search: Lexical ranking function that scores term frequency and document length for exact FAQ matching.
Reciprocal Rank Fusion ﴾RRF:﴿ Ensemble algorithm combining dense vector and lexical rankings to produce optimal hybrid search results.
